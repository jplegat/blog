## Project Overview

Personal blog (jp.legat.io) built with Astro 5, using the Terminal theme (ported from Hugo). Static site deployed to GitHub Pages at `https://jplegat.github.io/blog`.

## Commands

- `npm run dev` — local dev server (serves at root `/`)
- `npm run build` — production build (outputs to `dist/`, uses `/blog` base path)
- `npm run preview` — preview production build locally
- `./build.sh` — rebuild and redeploy Docker container (Nginx serving static files on port 8888)

There are no tests or linters configured.

## Architecture

**Content model:** Posts live in `src/content/posts/` as Markdown files with frontmatter (`title`, `description`, `pubDate`, `author`, `tags`). Posts with `draft: true` are filtered out on the index page. Tags are plain string arrays — each tag generates a page at `/tags/[tag]/`.

**Routing:** Astro file-based routing in `src/pages/`. Post detail pages use `src/pages/posts/[...slug].astro` (catch-all). Tag pages use `src/pages/tags/[tag].astro`. RSS feed generated by `src/pages/rss.xml.js`.

**Layouts:** `BaseLayout.astro` is the shell (head, nav, footer, global CSS imports). `PostLayout.astro` wraps `BaseLayout` and adds post metadata display and code-copy functionality.

**Base path handling:** `astro.config.mjs` sets `base` conditionally — `/` for dev and Docker (`DOCKER_BUILD=true`), `/blog` for production GitHub Pages builds. All internal links in layouts use the `base` variable, not hardcoded paths.

**Styling:** CSS custom properties in `src/styles/terminal.css` control the color scheme. All CSS files are imported via `<style is:global>` in `BaseLayout.astro`. Compatible with panr's Terminal.css color scheme generator.

**Deployment:** Push to `main` triggers GitHub Actions (`.github/workflows/deploy.yml`) which builds and deploys to GitHub Pages via `withastro/action`.
